# TESTMEV — โปรแกรมเทรดจำลอง + Exness MT5

แอป Python ภาษาไทย หน้าจอมืด มีกราฟแท่งเทียน บอท EMA ตัวอย่าง ปุ่ม Buy/Sell ประวัติออเดอร์ และกราฟมูลค่าพอร์ต ใช้ได้โดยไม่สมัครบัญชี

**เวอร์ชันนี้เทรดในบัญชีจำลองเท่านั้น** การเชื่อม Exness MT5 ใช้อ่านราคาและยอดบัญชี ไม่ส่งคำสั่งเงินจริงหรือคำสั่งไปบัญชี Demo ของ MT5 กลยุทธ์ EMA เป็นตัวอย่างสำหรับทดสอบการทำงาน ยังไม่ใช่กลยุทธ์ที่กำหนดตามความต้องการของผู้ใช้

## เปิดใช้ Windows EXE

1. แตกไฟล์ `TESTMEV-Windows-x64.zip` ทั้งโฟลเดอร์ก่อน
2. ดับเบิลคลิก `TESTMEV.exe` — ไม่ต้องติดตั้ง Python
3. หน้าจอจะเปิดเป็นหน้าต่างแอปผ่าน Microsoft Edge ถ้าไม่มี Edge จะเปิดในเบราว์เซอร์เริ่มต้น
4. ใช้ได้ทันทีด้วยบัญชีจำลอง $5,000 เลือก XAUUSD, EURUSD หรือ BTCUSD แล้วกด Buy/Sell หรือเริ่มบอท

รองรับ Windows 10/11 แบบ x64 ต้องเก็บโฟลเดอร์ `app` และ `runtime` ไว้ข้าง EXE นี่เป็นชุด Portable ไม่ใช่ EXE ไฟล์เดียว ตัว EXE ยังไม่มีลายเซ็นผู้เผยแพร่ดิจิทัล ไม่ต้องใช้สิทธิ์ Administrator

เมื่อเลิกใช้งาน กด **ออกจากโปรแกรม** ในแถบซ้าย ระบบจะหยุดบอท ปิดออเดอร์จำลอง และเก็บ CSV บนเครื่อง การปิดเฉพาะหน้าต่างจะยังปล่อยโปรเซสทำงานอยู่ ถ้าเปิดซ้ำจะมีข้อความว่าโปรแกรมทำงานอยู่แล้ว

## เชื่อม Exness MT5

1. ติดตั้งและเปิดโปรแกรม **Exness MetaTrader 5** บน Windows เครื่องเดียวกัน
2. ล็อกอินบัญชีผ่านโปรแกรม MT5 ตามปกติ แอปนี้ไม่ขอและไม่เก็บรหัสผ่าน
3. กด **Exness / MT5** ทางซ้าย
4. ระบุชื่อสินทรัพย์ให้ตรงกับ Market Watch เช่น `XAUUSDm`, `XAUUSDc` หรือ `XAUUSD`
5. กดเชื่อมต่อ ถ้ามีหลายโปรแกรม MT5 ให้ระบุพาธ `terminal64.exe` ของตัวที่ต้องการ

หน้าต่างการเชื่อมต่อจะแสดงยอดบัญชี สถานะ Demo/Real ราคาซื้อขาย และกราฟ M1 จาก MT5 บัญชีหลักในหน้าจอเทรดยังคงเป็นบัญชีจำลองเสมอ สินทรัพย์และข้อกำหนดสัญญาของโบรกเกอร์อาจต่างจากค่าจำลอง ราคาที่ไม่มีการอัปเดตเกิน 2 นาทีจะมีข้อความบอกอายุราคา

การเชื่อมบัญชี Exness จริงต้องทดสอบบน Windows ที่เปิด MT5 และมีบัญชีเข้าสู่ระบบอยู่ก่อน ไม่สามารถยืนยันการเชื่อมบัญชีของผู้ใช้จากเครื่องพัฒนานี้ได้

## รันจาก VS Code

ใช้ Python 3.11 ขึ้นไป (ชุด Portable รวม Python 3.12.10):

```powershell
python main.py
```

โหมดจำลองใช้ Python standard library ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม เปิดโฟลเดอร์โปรเจกต์ใน VS Code ติดตั้ง Python extension เลือก Python interpreter แล้วกด F5 ได้เลย

ถ้าจะเชื่อม MT5 เมื่อรันจากซอร์ส ให้ใช้ Python 3.12 x64 บน Windows:

```powershell
python -m pip install -r requirements-mt5.txt
python main.py
```

## สิ่งที่ใช้งานได้

- กราฟแท่งเทียนจำลอง, EMA เร็ว/ช้า, ช่วง M1/M5/M15, ขยายกราฟ และดูราคาเมื่อเลื่อนเมาส์
- เปิด/ปิด Buy และ Sell จำลอง พร้อมจำกัดจำนวนออเดอร์และตรวจ margin
- Stop Loss / Take Profit เป็น **ระยะราคา** เช่น XAUUSD ระยะ 8 ที่ 0.01 lot ≈ $8 ก่อนค่าใช้จ่าย
- บอท EMA Crossover เข้าเมื่อเกิดการตัดกันเท่านั้น การกดเริ่มอาจต้องรอสัญญาณ
- ปุ่มหยุดบอทหยุดเปิดออเดอร์ใหม่ แต่ SL/TP ของออเดอร์เดิมยังทำงาน ปุ่มหยุดและปิดทั้งหมดจะทำทั้งสองอย่าง
- Backtest บนข้อมูลสร้างจำลอง 600 แท่ง แสดงจำนวนรายการ กำไรสุทธิ Win rate และ Max drawdown
- ประวัติรายการและส่งออก CSV, กราฟ equity, บันทึกระบบ, บันทึกการตั้งค่าลงเครื่อง

สมมติฐานการจำลอง: เงิน USD $5,000, leverage 1:100, commission ต่อรอบ $7/lot, spread คงที่ตามสินทรัพย์ ขนาดสัญญา XAUUSD 100, EURUSD 100000, BTCUSD 1 ต่อ lot SL/TP ตรวจจากราคาที่สังเกตทุก tick และใช้ราคานั้นเมื่อข้ามระดับ ไม่จำลอง liquidity, slippage, swap หรือกฎ margin ทั้งหมดของโบรกเกอร์ กราฟเดินเร็ว 1 แท่งต่อ 2 วินาทีตามช่วงเวลาที่เลือก จึงอาจแสดงเวลาจำลองในอนาคต ผลทดสอบนี้ไม่ใช่ผลตอบแทนจากข้อมูลตลาดย้อนหลังจริง

## ข้อมูลบนเครื่อง

Windows: `%LOCALAPPDATA%\TESTMEV`

Linux/macOS: `~/.local/share/TESTMEV` หรือกำหนด `TESTMEV_DATA_DIR` เอง

- `settings.json`: การตั้งค่าบอท ไม่เก็บรหัสผ่าน
- `trades-*.csv`: ประวัติรอบที่จบเมื่อออกอย่างปกติหรือรีเซ็ตบัญชี
- `launcher.log`: รายละเอียดเริ่มโปรแกรม Windows

เปิดแอปใหม่เริ่มบัญชีจำลองรอบใหม่ ไม่กู้สถานะออเดอร์เดิม ถ้าปิดโปรเซสแบบบังคับหรือไฟดับ รายการรอบปัจจุบันที่ยังไม่ส่งออกอาจไม่ถูกเก็บ ใช้ปุ่มส่งออก CSV ได้ระหว่างใช้งาน


## สร้างชุด Windows Portable ใหม่

ติดตั้ง MinGW-w64 ซึ่งมี `x86_64-w64-mingw32-gcc` แล้วรันบน Linux หรือ Windows:

```sh
python scripts/build_portable.py
```

สคริปต์โหลด CPython จากแพ็กเกจทางการของ Python Software Foundation บน NuGet และ Windows wheels ของ MetaTrader5/NumPy จาก PyPI พร้อมตรวจ SHA256 ตาม `scripts/windows-dependencies.json` ทุกไฟล์ สร้าง `dist/TESTMEV-Windows-x64.zip` และ checksum โดยไม่ใช้ PyInstaller หรือปิดการตรวจ TLS ไฟล์ LICENSE ของ runtime และ dependencies อยู่ในชุดที่แจก

## โครงสร้างสำหรับพัฒนากลยุทธ์ต่อ

- `trader/engine.py`: บัญชีจำลอง, การคิด P/L, SL/TP, EMA ตัวอย่าง และ backtest
- `trader/mt5_bridge.py`: ตัวเชื่อม MT5 แบบอ่านข้อมูล ไม่มี `order_send`
- `trader/server.py`: API เฉพาะ loopback, ตรวจ Host/Origin และ session token ของคำสั่ง
- `trader/static/`: หน้าจอและกราฟ ไม่ใช้ CDN หรือส่งข้อมูลออกภายนอก
- `main.py`: เปิดแอปและจัดการการออกจากโปรแกรม

ก่อนเพิ่มการส่งคำสั่งจริง ต้องกำหนดเงื่อนไขเข้าออก ขนาดความเสี่ยงต่อรายการ ขีดจำกัดขาดทุน และการกู้คืนสถานะกับบัญชี MT5 ให้ชัดเจน
