# TESTMEV 1.1.0 — กราฟสดจาก Exness MT5

กราฟหลักใช้ **ราคา Bid/Ask และแท่งเทียนจริงจากโปรแกรม MetaTrader 5** ที่ล็อกอินบัญชีโบรกเกอร์บนเครื่องเดียวกัน ตรวจข้อมูลทุก 0.5 วินาที ไม่มีการสุ่มราคา ไม่มีกราฟตัวอย่างทดแทนเมื่อเชื่อมต่อไม่ได้

บัญชี $5,000, ออเดอร์และบอทใน TESTMEV ยังเป็น **paper trading** ใช้ราคา MT5 ในการจำลอง ไม่ส่งคำสั่งซื้อขายไปบัญชี Exness

## เปิดใช้ Windows EXE

1. ดาวน์โหลดชุดล่าสุดจาก [โฟลเดอร์ downloads](downloads/README.md)
2. ปิด TESTMEV รุ่นเก่าด้วยปุ่มออกจากโปรแกรม แล้วแตก ZIP ใหม่ทั้งโฟลเดอร์
3. เปิด **Exness MetaTrader 5** และล็อกอินบัญชีให้เรียบร้อย
4. เปิด **TESTMEV.exe** จากโฟลเดอร์ใหม่ ไม่ต้องติดตั้ง Python
5. กด **เชื่อม Exness MT5** บนกราฟ ระบุชื่อสินทรัพย์ตาม Market Watch เช่น XAUUSDm, XAUUSDc หรือ XAUUSD
6. เมื่อขึ้น **LIVE · MT5** กราฟหลักและปุ่ม Buy/Sell จะใช้ราคาจาก MT5 ชุดเดียวกัน

รองรับ Windows 10/11 x64 ชุด Portable รวม Python 3.12.10, MetaTrader5 และ NumPy ต้องเก็บ app/ และ runtime/ ข้าง EXE โปรแกรมเปิดผ่าน Microsoft Edge แบบหน้าต่างแอป หรือเบราว์เซอร์เริ่มต้นหากไม่มี Edge ตัว EXE ยังไม่มีลายเซ็นดิจิทัลผู้เผยแพร่

ถ้ามีหลาย MT5 ให้ใส่พาธ terminal64.exe ของโปรแกรมที่ต้องการ ไม่ต้องใส่รหัสผ่านใน TESTMEV โปรแกรมจำเฉพาะพาธและชื่อสินทรัพย์เพื่อเชื่อมให้อัตโนมัติครั้งถัดไป

## กราฟและสถานะราคา

- M1/M5/M15 ขอแท่งเทียนช่วงเวลานั้นจาก MT5 จริง แท่งปัจจุบันอัปเดตตาม MT5 โดยไม่เพิ่มแท่งตามเวลาในเครื่อง
- เส้นราคาล่าสุดและปุ่ม Buy/Sell ใช้ Bid/Ask จาก symbol_info_tick โดยตรง Spread คือ Ask − Bid จริง
- กราฟแสดงเวลา **UTC** เพื่อให้ตรงกับ timestamps ของ API ไม่สร้างเวลาจำลองในอนาคต
- ถ้ายังไม่ได้เชื่อม จะไม่มีแท่งเทียนหรือราคาปลอมปรากฏ
- หาก tick เก่ากว่า 15 วินาที, เวลา tick อยู่ในอนาคตผิดปกติ หรือไม่ได้รับผลตรวจข้อมูลเกิน 3 วินาที จะขึ้น **ราคาไม่เป็นปัจจุบัน**
- หาก MT5 หลุดจากโบรกเกอร์ จะค้างกราฟล่าสุดและขึ้น **MT5 ขาดการเชื่อมต่อ** การไม่มี tick ใหม่อาจเกิดจากตลาดปิดหรือเครือข่าย ไม่ได้สรุปว่าตลาดเปิดอยู่
- เมื่อราคาไม่พร้อม ปุ่มซื้อขายถูกปิดและบอทถูกพัก SL/TP จะไม่สร้างรายการปิดจากราคาค้าง เมื่อราคากลับมา SL/TP ตรวจจากราคาที่ได้รับใหม่ และต้องกดเริ่มบอทอีกครั้ง
- ถ้า MT5 ยังไม่มีประวัติแท่งเทียน ให้เปิดกราฟสินทรัพย์เดียวกันใน MT5 เพื่อโหลดข้อมูล

เปิด/ปิดบัญชีจริงหรือ Demo ใน MT5 ได้ แต่ TESTMEV ใช้ข้อมูลสำหรับอ่านเท่านั้น ไม่เรียก order_send

## Paper trading และ backtest

- เริ่มเงินจำลอง USD $5,000 ออเดอร์เข้า Buy ที่ Ask และ Sell ที่ Bid จาก MT5
- ขนาดสัญญา, digits และข้อกำหนด lot อ่านจาก MT5 ไม่สมมติว่าสัญลักษณ์มีชื่อหรือขนาดเดียวกันทุกโบรกเกอร์
- Paper P/L รองรับสินทรัพย์ที่ currency_profit เป็น USD เท่านั้น สินทรัพย์สกุลอื่นยังดูกราฟได้
- SL/TP เป็นระยะราคา ไม่ใช่จำนวนเงิน ตรวจจาก tick ล่าสุดที่ได้รับและอาจปิดข้ามระดับเมื่อราคากระโดด
- บอทตัวอย่าง EMA ใช้เฉพาะแท่งที่ปิดแล้ว ตรวจแต่ละแท่งครั้งเดียว ไม่เปิดซ้ำทุกครั้งที่ poll และไม่เปิดทันทีจากสัญญาณเก่าตอนเพิ่งเชื่อม
- Margin paper สมมติ leverage 1:100 และ commission $7/lot ต่อรอบ ยังไม่จำลอง swap, liquidity, execution latency หรือข้อกำหนด margin ของ Exness ทั้งหมด
- Backtest โหลดแท่งปิดจริงสูงสุด 800 แท่งจาก MT5 ไม่มีชุดข้อมูลสุ่ม ใช้ EMA ของแท่งก่อนหน้าแล้วจำลองเข้าแท่งถัดไปที่ราคาเปิดและ spread ที่บันทึกในแท่ง
- Backtest ประเมินที่จุดเปิดแท่ง ไม่จำลองเส้นทางราคาในแท่ง ผลจึงเป็นแบบจำลองและไม่ใช่ประวัติการซื้อขายจริงของบัญชี
- ถ้าไม่มีข้อมูลย้อนหลังหรือข้อมูลไม่พอ จะแสดงข้อผิดพลาด ไม่ทดแทนด้วยข้อมูลที่สร้างเอง

## ข้อมูลบนเครื่องและการออกจากโปรแกรม

Windows: %LOCALAPPDATA%\TESTMEV

Linux/macOS: ~/.local/share/TESTMEV หรือกำหนด TESTMEV_DATA_DIR

- settings.json: การตั้งค่าบอท
- connection.json: พาธโปรแกรม MT5 และชื่อสินทรัพย์ ไม่มีรหัสผ่าน
- trades-*.csv: รายการ paper ที่ปิดแล้ว
- open-paper-*.json: ออเดอร์ paper ที่ยังไม่ปิดเมื่อออกจากโปรแกรม ไม่มีการสร้างราคาออกขึ้นเอง
- launcher.log: รายละเอียดการเริ่มโปรแกรม Windows

กด **ออกจากโปรแกรม** เพื่อหยุดบริการและเก็บประวัติ การปิดเฉพาะหน้าต่างยังปล่อยโปรเซสทำงานอยู่ การเปิดใหม่เริ่มบัญชี paper รอบใหม่และไม่กู้คืนออเดอร์รอบเดิม เก็บการตั้งค่าไว้ การบังคับปิดโปรเซสอาจทำให้ประวัติรอบนั้นไม่ถูกบันทึก ควรส่งออก CSV ก่อน

## รันจาก VS Code

ใช้ Python 3.12 x64 บน Windows เพื่อเชื่อม MT5:

~~~powershell
python -m pip install -r requirements-mt5.txt
python main.py
~~~

เปิดโฟลเดอร์ใน VS Code ติดตั้ง Python extension แล้วกด F5 ได้ Linux/macOS เปิดหน้าแอปได้ด้วย Python 3.11+ แต่ไม่สามารถเชื่อมไลบรารี MT5 สำหรับ Windows และจะไม่มีราคาบนกราฟ

## ทดสอบ

~~~sh
python -m unittest discover -s tests -v
python main.py --smoke-test
~~~

ทดสอบ UI เพิ่มเติมด้วย Playwright และ Chromium:

~~~sh
python -m pip install playwright
python -m playwright install chromium
python scripts/browser_smoke.py
~~~

ชุดทดสอบใช้ terminal fixture ที่ระบุชัดเจนใน tests/ เท่านั้น ไม่มีการนำ fixture ไปเป็นแหล่งราคาสำรองในแอป

การเชื่อมบัญชี Exness จริงต้องทดสอบบน Windows ที่เปิด MT5 และล็อกอินอยู่ เครื่องพัฒนานี้ใช้ mocks ตรวจการรับข้อมูล, API และ UI และใช้ Wine ตรวจตัว EXE ไม่ได้ยืนยันการเชื่อมบัญชี Exness ของผู้ใช้

## สร้าง Windows Portable ใหม่

ติดตั้ง MinGW-w64 แล้วรัน:

~~~sh
python scripts/build_portable.py
~~~

สคริปต์ใช้ CPython จากแพ็กเกจทางการของ Python Software Foundation บน NuGet และ Windows wheels ของ MetaTrader5/NumPy จาก PyPI ตรวจ SHA256 ตาม scripts/windows-dependencies.json และคงการตรวจ TLS ไฟล์ LICENSE รวมอยู่ในชุดที่แจก

ส่วนสำคัญของโค้ด:

- trader/mt5_bridge.py: ดึงราคา แท่งเทียน ประวัติ และข้อมูลสัญญาจาก MT5
- trader/engine.py: บัญชี paper ที่รับข้อมูลตลาดเท่านั้น ไม่มีตัวสร้างราคา
- trader/server.py: polling ทุก 0.5 วินาที, ตรวจสถานะ, API บน loopback
- trader/static/: กราฟสดและหน้าจอภาษาไทย ไม่มี CDN
